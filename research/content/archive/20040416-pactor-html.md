ARES/RACES PACKET TO PACTOR GATEWAY

Gateway Instructions for emergency situations. Sending messages thorough the gateway.

1. On 145.530 Connect to EWARG Then connect to W7GBU-7

2. After connect script is given to you and you have a command prompt type port 1. This swithches you to HF PACTOR.

3. Then connect to K7ITL. This is done by by typing C K7ITL. You should receive the following.

\*\*\* CONNECTED to K7ITL Type H for help.

(AEA PK-900) 13328 free.

Bulletin #1 is gateway instructions and #3 is statewide configuration.

Yourcall DE K7ITL (A,B,G,H,J,K,L,R,S,V,?)

4. Then Type in g for gateway access. You will receive the following.

++ K7ITL AEA Cross-mode Gateway. Type ? for help.

++ Cross access to Port 2, 1200 bps Packet. Your ID is Yourcall-15.

Yourcall de K7ITL (B,C,D,J,L,N,S,?)>

5. Then type C wa7phd-7. You will receive the following.

++ CONNECTED to WA7PHD-7 at K7ITL-7

Connected to EOC. Maildrop is WA7PHD-8.

6. Then type in your message. After you are done with your message hold down your Control button and hit D (Ctrl. D). This will disconnect you from the system entirely.

7. If you are disconnected for some reason keep trying.
